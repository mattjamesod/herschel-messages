# Herschel Messages

**Herscel Messages** is a small open-source package that allows a program to send and receive cusomt mesages asynchronously through an [`AsyncChannel`](https://github.com/apple/swift-async-algorithms/blob/main/Sources/AsyncAlgorithms/AsyncAlgorithms.docc/Guides/Channel.md).

## Features:

- Multiple subscribers to a single channel of events
- SwiftUI view modifiers to update view state on an event being received
- Listen only for events that match a predicate
- Minimal overhead and boilerplate
